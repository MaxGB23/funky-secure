# Diagram

`diagram.jpg` is the README artwork. It belongs to the same visual family as the diagram in the
`funky-forge` repository, so the two products read as siblings.

It was produced by an image model, using that diagram as the rendering style reference only, and then
corrected in three targeted editing passes: one that replaced every word with the rows of this
product, one that removed a repeated line and relabelled a heading, and one that deleted a duplicated
stamp. The prompts are conversational, not committed: what matters for the next diagram is the method
— style from the sibling product, content as an explicit old-to-new list, and corrections as removals
rather than regenerations.

Two things to keep true if it is ever redrawn: every string in it is a fact about the tool (the twelve
rules and their four families, the exit codes, the commands the plan prints), and the machine is drawn
as read-only, because the tool never installs anything and never reaches the network.
